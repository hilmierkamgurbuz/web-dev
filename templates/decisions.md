# Decisions

One line per architecture or product decision that binds future tasks. A reversed decision gets a new id, and the old line is marked `superseded by D-###`, never deleted. `affects:` names paths or features; `wd check` warns when a named path no longer exists.

```
D-### | <decision in one sentence> | why: <reason> | affects: <paths or features> | date: <YYYY-MM-DD> | status: active
```
